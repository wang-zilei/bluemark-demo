## 检索到的方法

以下依据于 2026-10-18 实际抓取的一手规范；外观判断另以截图为准。详细原文与数值见 `research.md`。

1. **动作层级：** [Ant Design Button](https://ant.design/components/button/) 建议每个 section 至多一个 primary，其他动作分 default/text/link。BlueMark 需要的是优先级分配，不是每个按钮变厚或变亮。
2. **空间层级：** [Atlassian Elevation](https://atlassian.design/foundations/elevation/) 区分 default、sunken、raised、overlay。普通表格和表单保持平面；下拉、抽屉、弹窗才真正浮起；不要用阴影代替分组。
3. **颜色语义：** [Radix Scale](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) 把背景、悬停、按下/选中、边框、实底、文字分开。不是一个 `--primary` 和一个 `--muted` 应付所有状态。
4. **动效：** [Carbon Motion](https://www.carbondesignsystem.com/building-blocks/foundations/motion/overview) 的 productive motion 适合工作工具。按钮用短反馈，面板用有来源的进入/退出，不让每行表格上浮。其官方时长梯度为 70/110/150/240/400/700ms，不是所有动作统一套一个值。
5. **可读性：** [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 普通文字至少 4.5:1；必要控件边界/状态识别一般至少 3:1。不同层级不能以不可读为代价。

## 可借鉴的 Token

以下是 **BlueMark 的建议映射，不是上述系统的官方默认值**。保留现有品牌蓝 `#245BFA`，其对白色约 5.31:1，没必要因改版换成别家品牌色。

| Token 组 | 建议 | 用途 |
| --- | --- | --- |
| 文字 | primary `#20242C`；secondary `#566170`；muted `#687386` | 正文、辅助事实、元信息；仍保持可读 |
| 表面 | canvas `#F2F4F7`；base `#FFFFFF`；hover `#EDF1F7`；selected `#E5ECFF` | 工作背景、正文工作面、临时指向与持续选中分开 |
| 按钮 | primary `#245BFA`；hover `#174EE5`；pressed `#1643BD` | 默认、悬停、按下；danger 独立语义 |
| 边框 | separator `#E0E4EB`；interactive `#7B8794` | 非交互分隔与需要识别的控件边界分开，不把全站边框加深 |
| 字号 | 页面标题 26–28px；正文 14–16px；标签 12–13px | 控制层级数量，不再堆 9/10/11px 微字 |
| 尺寸 | 按钮高 44px；圆角 6px；对象 8px；间距 4/8/12/16/24/32px | 稳定尺寸、对齐和点击面积 |
| 动效 | press 70ms；hover 110ms；panel 200ms；`cubic-bezier(.2,0,.38,.9)` | 本项目取舍；panel200ms为建议，不声称 Carbon 官方值 |
| 阴影 | control `0 1px 2px rgb(20 35 65 / 16%)`；overlay `0 12px 28px rgb(20 35 65 / 18%)` | 小控件实体边缘与真正弹层分开，不全局卡片化 |

`prefers-reduced-motion` 下取消位移、缩放和旋转；保留即时文字、颜色与焦点。动画确认实际状态变化，不能冒充请求成功。

## 方向与落地顺序

先比较 `dir-1.html`、`dir-2.html`、`dir-3.html`，选择后再改正式产品。建议 **A 保留架构，吸收 C 的审核反馈**；B 可用于更突出营销作品的品牌表达。这是推荐，不代替用户选择。

1. 共享页头与文案清理。
2. 语义 token、字阶、按钮状态和操作优先级。
3. 产品介绍页与工作区视觉语法分离。
4. 全局组件状态、全部路由、窄窗口和减少动态偏好回归。

本轮没有替换正式 UI、没有调用模型、没有修改本地项目、没有写入长期偏好记忆。三方向只是验证视觉和交互的独立原型，按钮的原型状态不代表正式业务完成。
