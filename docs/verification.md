## 本次修复的回归风险

审查中发现的问题均在提交前修复，回归测试覆盖关键状态。

1. 合法 Brief 可选字段为空时，Mock 使用明确的待确认内容，不再生成违反 Schema 的空字段。
2. 内容保存校验合并后的完整记录，空标题、空正文和非法平台不能破坏持久化。
3. 编辑提交校验内容版本，生成期间禁止修改；重生成写回前也校验版本，失败保留原内容。
4. 复制项目不继承风险已处理与人工审核；内容或风险描述修改后需要重新确认。
5. 真实模型身份以服务端配置为准，不把浏览器模型名称冒充实际调用模型。
6. 公网模型请求必须 HTTPS；回环 HTTP 需显式允许，默认拒绝私网、重定向和跨源变更请求。

## 视觉优化复验

2026-10-18 按全局走查结果完成正式网页调整。原有 IA、路由、案例数据和图片保留。

1. 工作台及其他操作页移除装饰性全大写眉题与口号，保留状态、数据口径、密钥安全、异常及示例来源提示。
2. Landing 改成独立访客导航、产品名/类别、真实工作台预览和案例入口；不再把产品介绍页排成工作区延伸。
3. 建立语义色彩、文字和表面层级；正文与关键状态颜色更深。按钮实测具有 default/hover/pressed 差异，按压使用 1px 位移和内阴影。
4. 项目生成和人工审核的主动作随阶段变化，未完成审核时“继续审核”会导航到下一待审模块。
5. `npm run typecheck`、`npm test`（152 项）和 `npm run build` 通过。页面走查 10 个工作台/介绍路径，未发现 JS 错误；窄屏仍无页面级横向溢出。

## 仍未验证或未实现

当前是可运行、可审查的产品原型，不是生产级多租户 SaaS。

1. 未验证任何真实供应商的密钥、账户权限、模型质量、延迟、费用或生成成功率。
2. 不提供联网调研、真实广告投放、自动发布、实绩采集或营销效果保证。KPI 目标与实测值分开，实测值为未采集。
3. 未实现登录、RBAC、云端数据库、多浏览器同步、不可篡改审计、完整备份导入和后台任务取消。
4. 使用记录属于浏览器本地记录，可以被本地用户修改，不可作为不可抵赖的审计证据。
5. 没有执行 GitHub 推送或线上部署；仓库提供 CI 与静态托管路由配置，静态托管只运行 Mock。
